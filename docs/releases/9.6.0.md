Memonta 9.6.0（144）

- 新增可选的本机只读 MCP，在「设置 → MCP 集成」启用后，可向已授权的 AI 客户端共享录音、笔记、总结、转写、OCR、画面要点与待办。
- 支持全文关键词检索、带时间位置的转写查询与分页读取，提供本机 HTTP 接口和随 App 分发的 stdio 连接工具。使用时需保持 Memonta 运行。
- MCP 默认关闭。每个客户端独立授权，可限制共享日期并随时撤销；默认脱敏，隐藏条目始终不共享。外部客户端可能将读取的内容发送至其使用的云端模型。
- 为条目补齐稳定的磁盘身份，重建索引后仍可使用同一条目 ID；兼容旧目录与元数据。MCP 查询在磁盘对账、录音合并或更新安装期间暂停。
- 新增 MCP 文案覆盖全部 21 种界面语言。隐私政策更新为 5.0，升级后需要重新确认。
- 包含 9.5.3 的录音合并、磁盘恢复与全屏窗口修复。

验证：本机 461 项单元测试通过，5 项按条件跳过；包含真实回环 HTTP 与内嵌 stdio 工具查询、凭据撤销、授权范围、脱敏、元数据兼容、录音合并和窗口回归。多语言检查无错误，框架嵌入校验通过。未进行第三方客户端界面、Intel 真机及完整升级安装验证。

English

- Adds optional local, read-only MCP access. Enable it in Settings → MCP Integration to share recordings, notes, summaries, transcripts, OCR, visual notes and todos with authorized AI clients.
- Supports full-text keyword search, timestamped transcript queries and pagination through local HTTP or the bundled stdio helper. Memonta must remain running.
- MCP is off by default. Each client has separate authorization, an optional date limit and immediate revocation. Shared text is redacted by default; hidden entries are excluded. External clients may send retrieved content to their cloud models.
- Persists stable entry identities across index rebuilding while preserving legacy storage compatibility. Queries pause during disk reconciliation, recording merges and update installation.
- Includes MCP translations for all 21 UI languages. Privacy policy 5.0 requires renewed consent after upgrading.
- Includes the recording merge, disk recovery and full-screen window fixes from 9.5.3.

Validation: 461 local unit tests passed and 5 conditional tests were skipped, including HTTP and bundled stdio integration coverage, access control, redaction, legacy metadata, recording merges and window regressions. Localization and embedded-framework checks passed. Third-party client UI, Intel hardware and a complete upgrade installation were not tested.
