Memonta 9.6.3（147）

- 列表右键将录音、图片、视频清理合并为「清理源件」。提示列出各类源文件数量、预计空间、保留内容与不可撤销后果，点击「确定」才执行。
- 修复批量清理的目标收集：右键绑定到实际列表，使用完整多选集合；图片索引缺失或失效时核对实际 source.png。结果显示无源件跳过数量，并列出全部失败条目与原因。
- 新增大批量进度反馈，保留转写、OCR、总结、待办、关键帧及画面要点。视频继续要求可复用关键帧。
- 临时签名更新后的首次启动自动清理 Memonta 自身的旧 TCC 授权，减少手动删除旧记录再添加应用的步骤。同一代码身份重启不重复清理；首次使用相关功能仍需在系统弹窗中授权。
- 采集进行中、后台进程、测试或临时会话不清理授权；失败不记为成功并提示，进程有超时与取消保护。

此版本沿用未公证分发方式。长期跨版本保留系统授权需要稳定的 Developer ID 签名。

English

- Combines audio, image and video cleanup into Clean Up Originals in list context menus. A confirmation describes file counts, expected space, preserved content and irreversible consequences; cleanup starts only after OK.
- Repairs batch target collection by attaching the menu to the actual list, preserving the full selection, and checking source.png when an image index is missing or stale. Results list every failure and count entries without originals.
- Shows batch progress while preserving transcripts, OCR, summaries, to-dos, keyframes and visual notes. Video cleanup still requires reusable keyframes.
- Automatically clears Memonta’s own old TCC permissions on the first launch after an ad-hoc signed update. The same code identity is not reset on ordinary relaunches. Relevant features still ask for authorization through macOS.
- Does not reset permissions during capture, in workers, tests or transient sessions. Failures remain visible and retryable on the next launch, with process timeout and cancellation protection.

This release remains non-notarized. A stable Developer ID signature is needed for long-term permission continuity across versions.
