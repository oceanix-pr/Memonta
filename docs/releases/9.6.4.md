Memonta 9.6.4（148）

- 修复新增录音或更新侧栏列表后，标题、状态和时间叠在同一行的问题。条目增删、替换、重排和搜索过滤后正确清除旧行残留。
- 保留侧栏选中项与月份折叠状态；普通标题和状态更新继续原地刷新。
- 包含 9.6.3 的统一「清理源件」及批量清理修复，并在临时签名更新后首次启动时清理本应用的旧系统授权。使用相关功能时仍需通过 macOS 弹窗重新授权。

此版本沿用未公证分发方式。长期跨版本保留系统授权需要稳定的 Developer ID 签名。

English

- Fixes overlapping titles, status badges and timestamps after adding recordings or updating the sidebar. Clears stale row content when entries are inserted, removed, replaced, reordered or filtered.
- Preserves the sidebar selection and month expansion state. Ordinary title and status changes continue to update in place.
- Includes the unified Clean Up Originals action and batch cleanup fixes from 9.6.3, plus a one-time cleanup of Memonta's old system permissions after an ad-hoc signed update. Relevant features still request authorization through macOS.

This release remains non-notarized. A stable Developer ID signature is needed for long-term permission continuity across versions.
