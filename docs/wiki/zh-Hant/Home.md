## 專案概覽

Memonta 使用 Swift 6、SwiftUI、SwiftData，核心鏈路為：

```text
錄音 / 匯入音影片 → 系統語音識別 / 本地 WhisperKit / 雲端 Whisper 轉寫
→ 說話人分離 / 聲紋識別 → 繁簡歸一 / 詞典糾正
→ 加密儲存 → LLM 總結 → 可編輯待辦 → 使用者確認寫入提醒事項
```

- 應用內所有可排隊的處理任務（下載模型 / 轉寫 / 畫面分析 / 總結 / 潤色標題 / 拆解待辦）統一投遞到全域性處理佇列 [`TaskCenter`](02-Architecture.md)，右上角佇列面板可檢視 / 暫停 / 取消；列表右鍵、錄音錄屏播放條、筆記待辦旁三處提供「一鍵處理」，點選後先彈出預覽列出**將執行 / 將跳過**的步驟與雲端資料範圍，確認後才按「轉寫 → 畫面分析（錄屏）→ 總結 → 拆解待辦」序列執行（已完成的步驟預設跳過，只有顯式「重新轉寫」才覆蓋已有轉寫）。
- 圖片/文字快捷筆記和智慧截圖共用 QuickNote；截圖不是獨立持久化實體。文字筆記可用 macOS 系統音色在本機轉為語音並匯出 WAV/M4A（僅中文介面，見 [11 檢視](11-Views.md) §8.1）。
- 影片保留原檔案與音軌；畫面 Tab 管理原影片播放、關鍵幀和手動視覺分析，與轉寫共用時間軸。
- macOS 整合選單欄、全域性截圖熱鍵、麥克風與會議應用靜音檢測、Dock 顯隱。
- 本地檔案為權威資料，SwiftData 為索引；文字加密與雲端 PII 處理有各自邊界，詳見安全篇。
- 工程為 macOS 單平臺應用與測試；iOS 支援（含 iOS Share Extension）已取消。

## 維護方式

只更新受改動影響的篇章；每條事實只維護一個主要位置，其餘放連結。
使用檔名與符號定位，不維護原始碼行數、固定行號和構建號快照。
實現說明與待辦分開；功能改動同步對應 PRD 驗收，不把歷史審查“已透過”沿用為當前驗證結果。

英文版源文件位於 `en/`，繁中版位於 `zh-Hant/`（由簡中轉換，保留程式碼與路徑）。用 `python3 docs/wiki/publish_wiki.py --output <Wiki仓库目录> --refresh-traditional` 生成 GitHub Wiki 頁面；重新整理繁中需要 `opencc-python-reimplemented`。生成器校驗本地引用、頁面連結和程式碼圍欄，生成三語導航，但不自動提交或推送。檢查差異後分別提交主倉庫文件與 Wiki 倉庫；首次使用 Wiki 需先在 GitHub 網頁建立首頁。
