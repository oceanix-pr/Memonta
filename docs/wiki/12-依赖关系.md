# 12 · 依赖关系

## 1. SPM 三方依赖（project.yml）

| 包 | 版本 | 产品 | 用途 | 备注 |
|----|------|------|------|------|
| **WhisperKit**（argmaxinc/argmax-oss-swift） | from 0.9.0 | WhisperKit | 本地语音转写（CoreML 推理） | 模型经 `HF_ENDPOINT=https://hf-mirror.com` 镜像下载 |
| **KeychainAccess**（kishikawakatsumi） | from 4.2.2 | KeychainAccess | API Key / AES 密钥存取 | `.accessibility(.afterFirstUnlock)` |
| **SherpaOnnx**（k2-fsa/sherpa-onnx） | 固定 revision（见 project.yml） | **sherpa-onnx-shared** | 说话人分离（pyannote segmentation + 3D-Speaker embedding，CPU） | 用 shared 动态产品：静态 onnxruntime 产物是 ar archive 非标准 framework，嵌入签名会失败；通过固定提交避免上游变化破坏可复现性，升级后回归分离链路 |

`.packages/` 目录是 SPM 本地缓存（checkouts），非工程内容。

### SherpaOnnx 的特殊构建处理

`Scripts/fix_onnxruntime_framework.sh`（preBuild 脚本）：上游 onnxruntime shared xcframework 布局非标准（实体目录替代符号链接），构建前规范为标准 framework 布局 + 修正 dylib 引用，否则嵌入后 CodeSign 严格校验失败。

## 3. 模块间依赖图

### 3.1 服务依赖（谁用谁）

```
RecordingViewModel ──┬─→ WhisperLocalService ──→ WhisperKit(SPM)
                     ├─→ WhisperAPIService ──→ KeychainAccess(SPM)
                     ├─→ MeetingRecorderService ──┬─→ MicCaptureService
                     │                            ├─→ SystemAudioCaptureService
                     │                            ├─→ AppMuteDetector
                     │                            ├─→ MicMuteMonitor
                     │                            └─→ AudioConverter
                     ├─→ SpeakerDiarizationService ──→ SherpaOnnx(SPM)
                     │        └─→ VoiceprintStore（质心复用）
                     ├─→ ChineseConverterService
                     ├─→ TranscriptDictionaryService（词典读取）
                     ├─→ TranscriptCache（渲染缓存）
                     ├─→ LLMService ──→ PIIScrubService（脱敏编排）
                     │        └─→ TodoExtractionService
                     │              └─→ RemindersService（EventKit）
                     ├─→ EncryptionService（加密/解密）
                     └─→ FileSyncService（启动同步/删除协议）

QuickNoteViewModel ──┬─→ VisionOCRService（图片 OCR）
                     ├─→ LLMService（generateSummaryFromImage 多模态 / 文本总结 / 标题）
                     ├─→ TodoExtractionService + PIIScrubService
                     ├─→ EncryptionService
                     └─→ RemindersService

SettingsViewModel ───┬─→ KeychainAccess（API Key）
                     └─→ SpeakerDiarizationService（模型下载）

ScreenshotManager ───┬─→ RegionSelectionController（会话）
                     │       ├─→ OverlayAnnotationView（标注）
                     │       └─→ PinnedWindowSession（钉住）
                     └─→ ScreenCaptureKit（权限/直拍）

RootView ────────────┬─→ 全部 ViewModel（编排）
                     ├─→ TaskCenter（把转写/总结/画面分析/待办等构造成 Job/Step 投递；只调度）
                     ├─→ MenuBarController / GlobalHotkeyManager（通知）
                     └─→ ScreenshotManager（通知驱动）

SettingsView/SettingsViewModel ──→ TaskCenter（whisperDownloadJob 模型下载）

TaskCenter ──────────┬─→ WhisperModelDownloader（下载步骤，唯一支持暂停/续传）
                     └─→ 各 ViewModel 方法（Step 执行体；取消走既有 cancelXxx 入口）

PIIScanService ──────→ LLMService（本地模型分析）
```

### 3.2 数据层依赖

```
AudioRecording ──cascade──→ TranscriptSegment（一对多，级联删除）
AudioRecording / QuickNote ──folderName──→ 磁盘文件夹（权威源）
AudioRecording / QuickNote ──ProcessingStatus──→ TaskCenter 队列面板（重启后恢复展示「进行中 / 失败」）
FileSyncService ──→ AudioRecording + QuickNote（磁盘 → DB 补录）
TodoDocument（todos.json）──→ RemindersService（reminderIdentifier 清理）
所有加密字段 ──→ EncryptionService ──→ Keychain（密钥）
```

### 3.3 通知总线依赖（松耦合）

GlobalHotkeyManager / MenuBarController / ScreenshotManager → NotificationCenter → RootView（见 [02-整体架构](02-整体架构.md) §6）。服务之间不直接引用 UI，UI 通过通知响应服务事件。
