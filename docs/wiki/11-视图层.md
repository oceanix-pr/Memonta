## 2. RootView — 主枢纽

### 2.1 结构（分层计算属性防类型检查超时）

```
body = dialogLayers                      // 弹窗/确认/导出/分享
  .overlay(progressOverlay)              // 录音中/导入中的底部进度条
  .contextMenu(forSelectionType: ListItem.self)  // 列表上下文菜单
  .modifier(ExportModifiers)             // 转写/总结导出（.md + .pdf）+ 录音分享
  .modifier(LifecycleTasksModifier)      // 启动任务链（串行）
```

内部分三层：`observerLayers`（NavigationSplitView + onReceive 通知监听 + onAppear 首屏）→ `sheetAndAlertLayers`（Privacy/Onboarding/Settings/Help 弹窗 + 错误 alert）→ 对话框层。

### 2.2 关键机制

- **通知监听**：菜单栏录音控制、录音全局热键、截图热键/菜单、截图保存入库、截图权限/错误弹窗、设置/帮助/剪贴板笔记（完整表见 [02-整体架构](02-整体架构.md) §6）
- **首屏门控**：`hasAcceptedPrivacyPolicy` → PrivacyConsentView；`hasCompletedOnboarding` → OnboardingView；**大版本升级**（`onboardingCompletedVersion != currentAppVersion`）重新展示引导介绍新功能
- **侧边栏**：`RecordingListView` + 工具栏（**导入音频/视频**、新建快捷笔记、截图〔仅专业模式〕、删除、重命名、同步磁盘数据、开始/停止会议录音）+ macOS 文件拖拽导入（`AudioImportValidator` 校验）
- **详情分流**：按选中项类型分流 `RecordingDetailView` / `QuickNoteDetailView`，注入转写/取消/LLM 配置/提醒列表等依赖
- **处理队列接入**：详情列右上角工具栏常驻 `QueueToolbarButton`（图标随状态变化：有失败任务显示警示图标，否则按是否有活动任务区分；点击弹出 `QueuePanelView`）。RootView 的私有 extension 只做调度——把「转写 / 总结 / 润色标题 / 画面分析 / 拆解待办 / 一键处理」构造成 `TaskCenter` 的 Job/Step 投递，每个 Step 调用既有 ViewModel 方法并更新模型上的 `ProcessingStatus` 字段，并按上下文上报 `TaskErrorCode`（见 [02-整体架构](02-整体架构.md) §3.4）
- **一键处理三入口**：列表右键菜单、录音/录屏详情**播放条右侧**按钮、快捷笔记「拆解待办」**旁**按钮，均走 `presentOneClickPreview(_:)` → `OneClickPreviewView` 预览 → `enqueueOneClick(_:plan:)` 入队，链路为「转写（默认跳过已完成的，只有显式勾选「重新转写」才重跑并先备份手动编辑）→ 画面分析（录屏 / 导入视频）→ 总结 → 拆解待办」；文字/图片笔记无音轨，链路为「总结 → 拆解待办」。录音/录屏默认会议总结，文字/图片笔记按概要总结，**待办只落盘不写入提醒事项**。入队后顶部横幅提供「查看队列」入口（通知 `openTaskQueuePanel` 由工具栏按钮响应）
- **`ListItem` 选中模型**：`.recording(AudioRecording)` / `.quickNote(QuickNote)` 联合类型，支持 macOS List 多选（批量删除/导出）
- **导出子菜单**：转写与总结各自可导出 `.md` 或 `.pdf`（另保留复制文本与导出原始录音）。`.pdf` 走 `MarkdownPDFRenderer` 后台排版，排完再弹 `fileExporter`：排版不顶主线程，失败也能在用户选路径前弹错

## 4. RecordingDetailView — 录音详情

工具栏（播放控制、导出、删除）+ 音频播放器（AVAudioPlayer 封装，进度条/跳转）+ Tab 切换 **TranscriptView / SummaryView**；导入过原视频的**专业模式**条目额外显示 **VideoUnderstandingView**「画面」Tab（普通模式不展示该页签，规则见 `RecordingDetailView.availableTabs(experience:hasVideoAttachment:)`）。页签栏下方渲染共享 `LLMModelSelectorBar`（仅总结/画面页签显示，转写用 STT 配置不展示），取代此前两个子视图各画一份的同状态选择条（曾被误读为“两个下拉框”）；页内改选会写回全局活动大模型配置并持久化。**播放条右侧**提供「一键处理」按钮，点击先弹出 `OneClickPreviewView` 预览，确认后由宿主投递到处理队列。macOS 布局适配（参数顺序见 RootView 调用处）。

## 6. SummaryView — 总结视图

| 区域 | 说明 |
|------|------|
| 主体 | 流式输出区 + 编辑模式 + 待办列表 + sheet 弹窗（模型选择条由详情页共享） |
| 流式渲染 | 生成中 `MarkdownView` 实时渲染 `viewModel.summaryText`（流式 token） |
| 底部操作栏 | **会议总结/概要总结双按钮**（已有总结时为两个重新生成按钮，模板由用户显式选择、进行中禁用）、复制、编辑、**拆解待办**（→ 待办列表 sheet → 写入提醒事项） |

## 7. VideoUnderstandingView — 视频理解

视频条目的独立「画面」页由 `VideoUnderstandingView` 承担：内嵌 `VideoPlayer`，手动触发画面分析，明确显示“图片理解/本地 OCR”路径；缓存关键帧横向展示，点击后播放器精确跳转。切换到该页会暂停详情顶部的音频播放器，避免双路同时播放。

## 8. QuickNoteDetailView — 快捷笔记详情

图片预览 / 文字编辑 + AI 总结（流式）+ 待办提取 + 重命名/删除。与 RecordingDetailView 同构但面向 QuickNote 实体。底部操作栏在「拆解待办」**旁**提供「一键处理」（概要总结 → 拆解待办，先经 `OneClickPreviewView` 预览再入队）。顶部的模型选择器写回**全局活动大模型配置**并持久化（`SettingsViewModel.setActiveLLMConfig`），与设置页、录音详情的模型选择是同一份偏好，重开笔记或重启应用后保持一致。

## 9. SettingsView — 设置中心

### 9.1 布局

sidebar（分组列表，顶部带「设置与命令」搜索框）+ detail（分组表单）。

侧边栏搜索（`.searchable`）同时过滤设置页名称与应用命令：命令结果的名称与**当前快捷键**取自 `AppCommandCatalog`（与菜单栏、应用菜单、帮助页同一份描述），点选后跳到该命令对应的 `settingsDestination` 设置页；没有对应设置项的命令（如 ⌘N 新建笔记）只作名称与快捷键展示。

`SettingsView` 通过 `AppExperienceStore` 切换两套信息密度：普通模式只显示语音转写组件准备、智能服务连接、会议场景、热键、数据状态和关于；专业模式显示全部引擎、模型、捕获、热键、待办、词典、声纹和存储控制。模式开关位于“关于”，切换后当前不可见的设置页会自动回到首个可见分组。

### 9.2 设置分组

| 分组 | 内容 |
|------|------|
| stt 语音转写 | 引擎模式、本地模型管理（下载/选择文件夹）、云端 API 配置、语言；本地模型下载经处理队列（`TaskCenter.whisperDownloadJob`），可在队列面板暂停 / 继续（断点续传） |
| llm 大模型 | 多套配置 CRUD（name/baseURL/model/apiKey/isLocal/supportsVision）、连接测试 |
| recording 录音 | 来源（mic/systemAudio/mixed）、磁盘空间、静音提示选项 |
| screenshot 捕获 | 屏幕录制权限、默认捕获模式、录屏偏好（热键已迁出，见下） |
| hotkeys 热键 | **全局热键录制**（录音 / 截图 / 全屏直拍）、注册失败状态、`⌃⌘R` 冲突回退说明；两种模式均可见（普通模式隐藏「全屏直拍热键」行） |
| todo 待办 | 默认提醒事项列表、提前提醒量 |
| dictionary 词典 | 词条可视化管理（新建/编辑/删除）、**从声纹同步**、**更新去标识化**（PIIScanService） |
| voiceprints 声纹 | 声纹库管理（查看/删除） |
| data 数据 | 存储目录、磁盘同步、iCloud 状态 |
| about 关于 | 版本、隐私政策（含数据存储说明）、开源许可 |

### 9.3 普通模式的渐进披露

- 录音设置用“线上会议 / 面对面会议”映射采集源，不显示轨道、设备和静音策略。
- 总结只提供一个自动生成入口；模型选择、会议/概要模板指定、高级编辑和待办结构维护仅在 Pro 显示。
- 已有视频画面要点在普通模式仍可阅读，但不能新建/重新分析或清理原始视频，避免切换模式造成用户感知的数据丢失。
- 列表在普通模式收敛为单选，不显示批量、隐藏与标题润色入口；专业模式恢复原有多选与上下文菜单。

## 10. MarkdownView — Markdown 渲染器

自定义**块级**渲染器：标题（H1=largeTitle…H3=title2）、段落、项目列表、编号列表、代码块、引用、分割线。行内格式用 `AttributedString(markdown:options:.inlineOnlyPreservingWhitespace)`。用于转写与总结的统一渲染（TranscriptCache 提供解析后的块结构）。

## 11. HelpView / OnboardingView / PrivacyConsentView

- **HelpView**：内置帮助，覆盖会议录音、导入、快捷笔记、转写、声纹识别、总结、AI 待办、智能截图、菜单栏/后台录音、录音管理、数据隐私、快捷键；「快捷键」小节不硬编码，由 `AppCommandCatalog.shortcutReferenceIDs` 生成（名称与当前快捷键同上）
- **OnboardingView**：功能特性引导页（大版本升级重新展示）。普通模式使用精简主链路页面，Pro 保留完整功能介绍。引导页**不再引导下载模型**：转写与说话人区分的模型准备都发生在实际使用时（系统语音识别按语言资产按需安装，说话人分离模型由 `SpeakerDiarizationService.ensureModelsReady` 首次使用时自动下载，失败则提示并降级为不做分离）。
- **PrivacyConsentView**：首启隐私同意（数据收集、权限用途、传输、本地存储、屏幕共享说明、用户权利、第三方服务约束；`interactiveDismissDisabled` 强制选择）
