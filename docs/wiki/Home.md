## 项目概览

Memonta 使用 Swift 6、SwiftUI、SwiftData，核心链路为：

```text
录音 / 导入音视频 → 本地 WhisperKit 或云端 Whisper 转写
→ 说话人分离 / 声纹识别 → 繁简归一 / 词典纠正
→ 加密保存 → LLM 总结 → 可编辑待办 → 用户确认写入提醒事项
```

- 应用内所有可排队的处理任务（下载模型 / 转写 / 画面分析 / 总结 / 润色标题 / 拆解待办）统一投递到全局处理队列 [`TaskCenter`](02-整体架构.md)，右上角队列面板可查看 / 暂停 / 取消；列表右键、录音录屏播放条、笔记待办旁三处提供「一键处理」，点击后先弹出预览列出**将执行 / 将跳过**的步骤与云端数据范围，确认后才按「转写 → 画面分析（录屏）→ 总结 → 拆解待办」串行执行（已完成的步骤默认跳过，只有显式「重新转写」才覆盖已有转写）。
- 图片/文字快捷笔记和智能截图共用 QuickNote；截图不是独立持久化实体。
- 视频保留原文件与音轨；画面 Tab 管理原视频播放、关键帧和手动视觉分析，与转写共用时间轴。
- macOS 集成菜单栏、全局截图热键、麦克风与会议应用静音检测、Dock 显隐。
- 本地文件为权威数据，SwiftData 为索引；文本加密与云端 PII 处理有各自边界，详见安全篇。
- 工程为 macOS 单平台应用与测试；iOS 支持（含 iOS Share Extension）已取消。

## 维护方式

只更新受改动影响的篇章；每条事实只维护一个主要位置，其余放链接。
使用文件名与符号定位，不维护源码行数、固定行号和构建号快照。
实现说明与待办分开；功能改动同步对应 PRD 验收，不把历史审查“已通过”沿用为当前验证结果。
